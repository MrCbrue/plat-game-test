# Chronicles of Veyra: The Shattered Eclipse

A publish-ready 2D dark-fantasy action-platformer and Metroidvania built with HTML5 Canvas, a custom 60Hz sub-pixel platformer physics engine, a real-time multi-channel WebAudio music & SFX synthesizer, and a built-in Level Editor.

---

## 🌟 Key Features

### 1. Extensive 5-Act Story & 3 Branching Endings
- **Prologue & 5 Story Acts**: Awaken as **Kaelen**, the last Duskblade Sentinel, three winters after **Archon Malakor** shattered the **Solaris Crown** into five **Eclipse Shards**.
- **6 Interactive NPCs**: Speak with **Elder Lyra**, **Forgemaster Bram**, **Sylvi the Wayfarer**, **Unit-09 "Cog"**, **Mirabel the Archivist**, and **Vesper the Masked Crow**.
- **Moral Choices & Side Quests**: Decide whether to liberate or harvest the sentient Automaton Collective in Ironhearth Foundry, decipher **14 Ancient Lore Tablets**, and uncover the forbidden truth of **Nyxara, the Primordial Void**.
- **3 Distinct Endings**:
  - **Ending A — The Reforged Dawn**: Re-seal the Crown and restore the sun cycle.
  - **Ending B — Sovereign of the Eclipse**: Claim the five Shards for your own blade.
  - **True Ending — The Eternal Equilibrium**: Decipher the Lore Tablets and work with Elder Lyra & Archon Malakor to dissolve Nyxara forever.

### 2. Crisp 2D Platformer & Combat Mechanics
- **Fluid Traversal**: Variable jump height, **Coyote Time**, **Jump Buffering**, **Double & Triple Jump**, **Wall Slide & Wall Jump**, **Shadow Dash** (with i-frames and Shadow Gate phasing), and **Astral Grapple Hook**.
- **Deep Combat**: 3-Hit directional sword combos, **Downward Aerial Pogo Slashes** (bounce off enemies and spikes), **Aegis Parry** (reflect projectiles and stagger foes with slow-mo hit-stop), and **3 Castable Arcane Spells** (*Eclipse Lance*, *Solaris Nova*, *Astral Mend*).

### 3. RPG Progression, Forge, Relics & Skill Tree
- **5 Upgradable Weapons**: Temper blades up to **Tier +5** at Forgemaster Bram's Anvil.
- **12 Equippable Relics (Charms)**: Customize your loadout using the Relic Notch system.
- **15-Node Skill Tree**: Unlock abilities across the **Vanguard**, **Weaver**, and **Windrunner** paths.

### 4. 8 Interconnected World Zones, Boss Rush & Level Editor
- **8 Zones**: *Whispering Catacombs*, *Haven of Dusk (Hub Town)*, *Sunken Outskirts*, *Ironhearth Clockwork Foundry*, *Crystal Caverns of Echoing Frost*, *The Sunken Archive*, *The Obsidian Citadel*, and *The Astral Crucible (Boss Rush Arena)*.
- **5 Multi-Phase Bosses**: *Sylvanus the Mossbound Warden*, *Seraph-IX the Clockwork Valkyrie*, *Vaelen the Glacial Wyrm*, *Inquisitor Thorne*, and the 3-phase final boss *Archon Malakor*.
- **World Architect (Built-In Level Editor)**: Paint terrain tiles, hazards, enemies, grapple anchors, and chests, playtest immediately, and export/import custom level JSON.

## 🎮 Controls (Keyboard, Mouse & Gamepad)

| Action | Keyboard / Mouse | Gamepad |
| :--- | :--- | :--- |
| **Move** | `A` / `D` or `Left` / `Right` | Left Stick / D-Pad |
| **Jump / Double Jump / Wall Jump** | `W` / `Space` / `Z` | `A` (Cross) |
| **Drop Through Platform** | `S` / `Down` + `Jump` | `Down` + `A` |
| **Melee Sword Combo** | `J` or `Left Click` | `X` (Square) |
| **Aerial Pogo Bounce** | Hold `S` / `Down` + `Attack` in air | `Down` + `X` in air |
| **Aegis Parry / Deflect** | `F` / `V` or `Right Click` | `Y` (Triangle) |
| **Shadow Dash** | `K` / `Shift` / `X` | `B` (Circle) / `RB` |
| **Astral Grapple Hook** | `L` / `G` | `LB` |
| **Cast Spells** | `Q` (`1`), `E` (`2`), `R` (`3`) | `LT` / `RT` |
| **Drink Crimson Elixir** | `H` / `C` | — |
| **Interact (NPC / Shrine / Portal)** | `E` / `Up Arrow` | `Up` |
| **Sanctuary Menu / Map** | `Tab` / `M` / `Esc` | `Start` / `Select` |

## 🚀 Running & Testing

1. **Instant Browser Play**: Open `index.html` directly in any modern browser.
2. **Local Dev Server**:
   ```bash
   npm start
   # Opens at http://localhost:3000
   ```
3. **Run Automated Verification Suite**:
   ```bash
   npm test
   ```
